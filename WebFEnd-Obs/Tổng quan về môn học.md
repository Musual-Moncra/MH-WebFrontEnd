## 🎯 2. Tóm tắt nội dung, Mục tiêu & Chuẩn đầu ra (CLO)

### 2.1. Tóm tắt nội dung môn học
Học phần trang bị cho sinh viên kiến thức tổng quan và kỹ năng thực hành về các CSS framework và Javascript/TypeScript framework hiện đại trong phát triển ứng dụng web:
1. **Nền tảng cốt lõi:** Nắm vững cấu trúc, ngữ nghĩa của ngôn ngữ **HTML** (HTML5 Semantic) và **CSS** (CSS Box Model, Flexbox/Grid layout, Responsive design).
2. **CSS Framework:** Tìm hiểu sâu và vận dụng thành thạo **Bootstrap** để xây dựng giao diện tương thích đa thiết bị (Responsive web design).
3. **Javascript Framework:** Tìm hiểu sâu và vận dụng **Angular** (TypeScript) để phát triển ứng dụng Single Page Application (SPA), xử lý Component, Directives, Form, Routing và kết nối API qua HTTP Services.
4. **Ứng dụng thực tiễn:** Xây dựng hoàn chỉnh giao diện web phù hợp yêu cầu nghiệp vụ, kết hợp thao tác và hiệu ứng thân thiện với người dùng (UX/UI).
